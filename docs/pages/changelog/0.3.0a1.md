# Version 0.3.0a1

Released `UNRELEASED`

## Added

- Reconnection logic in the case that the voice server is deallocated.
- `PRIORITY` audio playing status - Configurable with `AudioPlayer`.`set_priority`.
- `VoiceWarningEvent` now dispatched for high packet loss or jitter.

## Breaking Changes

- `VoiceConnection`.`gateway_latency` renamed to `latency` as further `xyz_latency` methods will not be created; simplified.

## Fixed

- Bug in `AudioPlayer`.`set_volume` where it would set volume to `None` instead of defaulting back to connection/client configuration.
